About

GitDigest reads the key files of a public repository, summarizes them with a language model, and checks every citation against the real code. A citation that points to a missing file or line range is marked unverified.

  • Public GitHub repositories only.
  • Up to 25 files per run, README and manifests first.
  • Summaries only. It does not reproduce code.
  • Repo text is sent to the model you choose. Gemini's free tier may use prompts to improve Google's products, so avoid private code.

Summaries are written by a language model and can still be wrong. Open the citations before you rely on a claim.

About

GitDigest reads the key files of a public repository, summarizes them with a language model, and checks every citation against the real code. A citation that points to a file or line range that doesn't exist is marked unverified.

Limits

  • Public GitHub repositories only.
  • Up to 25 files per run, README and manifests first.
  • Summaries only. It does not reproduce the code.

Summaries are written by a language model and can still be wrong. Open the citations before you rely on a claim.
